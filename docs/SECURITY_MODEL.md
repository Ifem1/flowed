# Security model

Protected properties: terms are frozen; future steps cannot bypass the active step; the model cannot select payment; evidence cannot be replaced after creation; each step pays once; terminal refunds cannot replay; contests are bounded and cannot trap funds indefinitely.

Trust assumptions: public evidence may be false, unavailable, or misleading; GenLayer consensus judges the supplied snapshot rather than creating objective truth; redirect/effective-URL limitations may exist in the current web runtime; participants must choose meaningful criteria and sources; wallet key security is outside contract control.
